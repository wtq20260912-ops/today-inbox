## Mac 与 Windows：拖入、悬停、勾选

1. 完整解压。Mac 打开「今日收件箱.app」；Windows 打开 `TodayInbox.exe`，无需另外安装 .NET。
2. 桌面显示绿色悬浮图标。将聊天软件提供的可拖拽文字拖到图标上，松手加入待办。
3. 鼠标移到图标上，清单展开。点击任务前的方框完成，该项立即隐藏。
4. 鼠标离开清单后收起；图标可以拖动位置。关闭管理窗口仍在后台运行，右键图标可设置或退出。

部分微信 / 钉钉版本不允许把整条聊天气泡拖出。可以尝试选中文字后再拖；仍不支持时，复制文字后使用 **Control / Ctrl + Shift + T**，确认后添加。图片、语音和文件不作为文字待办导入。

Windows 右下角托盘图标可找回悬浮图标；可在右键菜单选择登录后自动打开。Mac 也保留菜单栏入口。

## 安卓：一条静音通知栏工作栏

1. 安装 APK，首次打开允许通知，并开启「工作栏（静音）」分类。
2. 点击「开启通知栏入口并收起」。以后点一次桌面图标即可启动后台。
3. **复制消息 → 下拉通知栏 → 展开「我的工作栏」→「粘贴／输入待办」→ 粘贴 → 提交。**
4. 在同一条工作栏里查看、翻页和勾选完成；误点标题与任务文字不会打开主界面。

工作栏默认无声音、无振动，不额外推送候选消息，无变化时不重复发送。通知内粘贴不需要悬浮窗、通知使用权或无障碍权限。需要主动设置时，长按桌面图标选择「设置与管理」。

OPPO 可在系统应用管理中允许后台活动；具体选项随 ColorOS 版本变化。暂不支持把整条聊天气泡直接拖进系统通知栏。系统省电、强制停止或重启仍可能结束后台，入口消失时重新点应用图标开启。

## 数据与升级

- 三个平台的数据各自保存在设备本机，暂不同步；不需要账号，不上传聊天或任务内容。
- 未完成任务跨天保留；完成后从日常清单隐藏，管理页面保留已完成记录。
- 安卓升级时直接覆盖安装，**不要先卸载**；卸载会删除本机数据。
- 桌面版升级时先退出程序再替换应用文件，不要删除应用的数据目录。桌面版可导出 JSON 备份，暂不提供跨平台导入。
- 这里是应用下载仓库。各平台版本号独立，日期标签只是本次统一发布的标识。

## 当前发布状态

这是试用版本。Mac 使用本地签名，未经过 Apple 公证；安卓使用个人试用签名；Windows 未做商业代码签名。遇到系统拦截时请先核对来源和 SHA-256 校验值，不需要关闭系统安全防护。

Windows 版本已通过交叉编译及 25 项核心数据检查，但尚未完成真实 Windows 10 桌面交互验收。安卓通知流程已通过自动化检查，ColorOS 的实际布局、后台和提醒表现仍需设备验证。不同版本微信 / 钉钉提供的拖拽能力可能不同。
